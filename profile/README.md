# 도하 · 노하우톡

### 직함 말고, 어떻게 여기까지 왔어요?

**한 사람의 경험이, 다른 사람의 다음 선택에 힌트가 되도록.**

노하우톡은 커리어 전환과 일의 경험을 대화로 연결하는 커피챗 프로젝트입니다. 정답을 가르치기보다, 어디서 시작했고 무엇을 해봤는지 묻습니다.

## 이런 이야기를 나눕니다

- **다른 출발점, 다음 커리어** · 미용 전공에서 컴퓨터공학과 개발로 건너온 경험을 바탕으로 전환의 시행착오를 이야기합니다.
- **주니어의 구체적인 성장** · Java·Spring·웹 개발과 주니어 멘토링 경험에서 배운, 작게 만들고 피드백받는 방법을 다룹니다.
- **기술 너머의 사람** · 커머스·데이터 시각화·챗봇 개발 경험과 사회복지에 대한 관심을 연결해, 누구를 위한 일인지 묻습니다.

## 대화를 시작하는 세 가지 질문

1. 지금 하는 일을 선택하기 전에는 무엇을 했나요?
2. 다시 시작한다면 어떤 시행착오를 줄이고 싶나요?
3. 다음 단계에서 가장 먼저 확인하고 싶은 것은 무엇인가요?
